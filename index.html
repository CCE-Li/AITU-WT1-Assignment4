About the project

This project is the completed Assignment #4. It is a small static website built with pure HTML, CSS, Bootstrap 5 and a bit of vanilla JavaScript — no framework and no build step.

Every task lives on its own page and is reachable from the navigation bar above. The five pages walk through the whole topic: a plain contact form, the same form with HTML5 validation attributes, a Bootstrap styled version, Bootstrap validation feedback (is-valid / is-invalid) and finally a full registration form that combines all of it.

Bootstrap is loaded from the jsDelivr CDN, so the site runs directly in a browser and can be published as-is on GitHub Pages.
