Part 1 · Basic HTML Forms

Task 0 — Simple Contact Form

A plain contact form. Every field has its own <label> that is connected to the input through the for and id attributes.

Contact us

What this page shows

  • A text input for the name, an email input and a textarea for the message.
  • A submit button that sends the form.
  • Labels are bound to inputs: <label for="contactEmail"> matches id="contactEmail", so clicking the text focuses the field and screen readers announce it.

Deliberately left out

This form has no validation at all: pressing Submit with empty fields is accepted. Task 1 adds HTML5 validation to the very same form.

The form uses action="#", so submitting only reloads the page — there is no backend behind this assignment.
