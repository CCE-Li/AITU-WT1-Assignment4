Part 1 · Basic HTML Forms

Task 1 — Form with HTML5 Validation

The same contact form, now with built-in validation attributes. No JavaScript is used on this page: the browser itself blocks the submit and shows its own error messages.

Contact us

Which attribute does what

Attribute Field Rule
required Name, Email, Message The field must not be empty.
type="email" Email The value must look like an email address.
minlength Name, Message A minimum number of characters.
maxlength Name, Message A maximum number of characters.
pattern Phone Must match the 123-456-7890 format.
title Phone Hint shown inside the validation message.

Test it

  • Press Submit with everything empty → the browser stops the form.
  • Type not-an-email → the email field is rejected.
  • Type 5551234 in the phone field → the pattern fails.
  • Write a 3-character message → minlength="10" fails.
  • Fill everything correctly → the form is submitted.

The error bubbles are drawn by the browser, so they cannot be styled. Task 3 replaces them with Bootstrap feedback messages.
