Bootstrap classes used

Class Effect
row g-3 Grid row with a consistent gap between fields.
col-md-6 Two fields side by side from the medium breakpoint up.
col-12 Full width field on every screen size.
form-label Spacing and weight for the field label.
form-control Styled text input and textarea.
form-select Styled dropdown with its own arrow icon.
form-check Checkbox (or radio) with an aligned label.
form-text Small helper text below an input.
