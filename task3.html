How the feedback works

  1. The form carries the class needs-validation and the attribute novalidate, so the browser does not show its own error bubbles.
  2. On every keystroke and on submit, JavaScript calls checkValidity() for the field.
  3. A valid field gets is-valid (green border) and a broken field gets is-invalid (red border).
  4. Bootstrap only displays the invalid-feedback / valid-feedback message that follows the coloured field, which is why the message shows up right below the input.
  5. setCustomValidity() allows messages that HTML alone cannot express, for example "Passwords do not match" in Task 4.

Test it

  • Leave the name empty and press Submit → "Name is required."
  • Type not-an-email → "Please enter a valid email address."
  • Type a real address → "Looks good!" appears in green.
  • A 5-character message → "Please write at least 10 characters."
  • Everything correct → the green success alert appears.
