Validation rules

Field Rule
First / Last name required minlength="2"

Country required on a select
Password minlength="8" pattern
Confirm password setCustomValidity() comparison
Gender required radio group
Hobbies Checkboxes, no constraint

Responsive layout

Fields sit in a row g-3 grid. Each one uses col-md-6, so on phones the form is a single column and from the medium breakpoint up it becomes two columns.

Try these cases

  • Submit while everything is empty → every field turns red.
  • Short password like abc123 → pattern and minlength fail.
  • Two different passwords → "Passwords do not match."
  • No gender selected → the radio group is marked invalid.
  • Press Reset → all values and error states are cleared.
